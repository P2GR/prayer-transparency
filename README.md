# Prayer Transparency

Makes overhead prayer icons floating above players semi-transparent.

## Features

- **Transparent overhead prayers** - master on/off.
- **Transparency level** - 0 (fully visible) to 10 (almost invisible).
- **Local player only** - apply only to your own prayer icon.
- **Icon vertical offset** - move the icon up or down.
- **Prayer icon style** - `Game` keeps the game's icon, `Clean` uses the prayer book icon without the beige circle.
